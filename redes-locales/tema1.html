Laboratorio de Redes Locales

Tipos de red

Toca cada zona para ver qué tipo de red cubre ese alcance. Después, en «Clasifica», decide para cada caso su alcance, su medio y su propiedad.

Elementos de una red local

La red de una oficina pequeña. Toca cada elemento para ver qué es y para qué sirve, juega a encontrarlos o elige el medio de transmisión adecuado para cada caso.

Topologías: corta un cable

Elige una topología y toca un cable para cortarlo (vuelve a tocarlo para repararlo). En estrella y árbol también puedes tocar un switch para que se averíe. En verde, los equipos que siguen comunicándose; en rojo, los que se quedan aislados.

Topologías: identifica y construye

En «¿Qué topología es?» mira el dibujo o lee el caso y elige la topología. En «Constrúyela» toca dos equipos para tender un cable entre ellos (tócalo otra vez para quitarlo) hasta formar la topología que se pide.
